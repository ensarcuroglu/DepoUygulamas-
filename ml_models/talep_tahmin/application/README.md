# Application

Use-case ve port sozlesmeleri bu katmanda yer alir.

Bu katman:

- domain kurallarini orkestre eder,
- infrastructure detaylarini arayuzler uzerinden kullanir,
- backend entegrasyonuna uygun DTO/input-output sozlesmesini korur.

Ornek ileride eklenecek dosyalar:

- `dto.py`
- `ports.py`
- `use_cases.py`
